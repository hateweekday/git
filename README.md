# 🐍 贪吃蛇 (Console Snake Game)

控制台版贪吃蛇游戏，使用 C 语言编写，运行于 Windows 控制台。

## 游戏截图

```
╔══════════════════════════════════════╗
║  ♥                · · ○ ○ ●        ║

╚══════════════════════════════════════╝
  ╔══════════════════════════════════╗
  ║  得分: 50   长度: 8   速度:135ms ║
  ║  W↑ S↓ A← D→  方向键均可        ║
  ║  P=暂停  Q=退出                 ║
  ╚══════════════════════════════════╝
```

## 编译运行

### 环境要求
- Windows 操作系统
- GCC (MinGW) 或其他 C 编译器

### 编译

```bash
gcc main.c -o snake.exe -Wall
```

### 运行

双击 `snake.exe` 或在命令行中运行：

```bash
snake.exe
```

## 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `P` | 暂停 / 继续 |
| `R` | 游戏结束后重新开始 |
| `Q` | 退出游戏 |

## 游戏规则

- 使用方向键或 WASD 控制蛇的移动方向
- 吃到红色食物 ♥ 得分 +10，蛇身长度 +1
- 每吃 5 个食物，蛇的移动速度会加快
- 撞到墙壁或自己的身体则游戏结束
- 按 R 键可重新开始

## 技术特点

- 使用 Windows Console API 实现流畅的画面渲染
- 蛇身渐变颜色显示
- 支持方向键和 WASD 双重操作方式
